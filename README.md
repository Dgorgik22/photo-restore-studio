# Photo Restore Studio — Alpha Lite 0.25

Local image restoration and upscaling for Windows, with a RUS / EN interface.

## Features

- Landscapes and interiors: cloud, water, foliage and surface detail support.
- Portraits: face, neck and hair restoration, with clothing texture support.
- Graphics and illustrations: enlargement and SVG vectorization. SVG is available only in this mode.
- PNG / JPEG, ×1–×8 and custom scale, 15–600 DPI, original/result comparison.
- Live language switching in Settings: RUS / EN.

The first Windows download and interface screenshot are being prepared for Releases. This is a public testing alpha; inspect faces, text and geometry in the output.

## Privacy

Processing is local. No account or API key is required. The release excludes the publisher’s credentials, personal settings, photographs, logs, caches and computer reports. There is no image upload or analytics feature. Optional update checks contact GitHub and can be disabled in Settings.
